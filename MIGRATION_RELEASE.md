# FreeTurn Windows v1.1.4 — переход в общий репозиторий

Windows, Linux и macOS теперь выпускаются вместе:
https://github.com/yaroslav4167/free-turn-desktop

Установите это обновление обычным способом. После перезапуска откройте
настройки и проверьте обновления ещё раз: клиент предложит общий v3.0.0,
выбирая только Windows-архив нужной архитектуры и проверяя SHA-256.

Это минимальное переходное обновление поверх v1.1.3: меняется источник
будущих обновлений. Сохранены исправления маршрутов Wintun, профили и
настройки. Серверы на VPS не изменяются. Старые релизы и теги остаются доступны.
